# 图谱：谁和谁总一起出现

单条记忆看不出关系，把它们叠起来才看得出来：某个项目总跟着某个人，某个人一出现就带着那件烦心事。
这一层**只做共现统计，不做推断**，纯规则、可重建、不调模型——和场景层一样，删了也能从 `entries` 重新长回来。

## 怎么算

`lib/graph.mjs` 的 `rebuildGraph(db, { space, scan, minCount })`，一次算一个空间：

1. 取这个空间最近的 `scan` 条记忆（默认 800），正文 `u` + `a` 用 `cueWords` 切成 2~4 字 n-gram，拉丁词单独抽、统一小写。
2. 出现次数 ≥ `minCount`（默认 3）的留下当实体；长串 openid / 十六进制 id / 12 字以上的纯小写串不算实体。
3. 一条记忆里同时出现的两个实体记一次共现；**共现 ≥ 2 次的才写成边**（`MIN_EDGE = 2`），只出现一次的当偶然。
4. 上限：实体 300 个、边 2000 条，按次数从高到低留。

产物是两张纯派生表（`entities` / `edges`，都带 `space`），整表按空间重建，随时可丢。

## 字段

### `GET /dsh-whale-memory/graph`

| 参数 | 缺省 | 说明 |
| --- | --- | --- |
| `space` | `default` | 看哪个空间；空间之间不串 |
| `limit` | `50` | 返回多少个实体，**上限 200**，超了就截断，不报错 |
| `sort` | `count` | `count` = 按出现次数；`degree` = 按连了几条边 |

```json
{
  "space": "default",
  "sort": "count",
  "limit": 50,
  "nodes": [{ "name": "米鱼", "count": 412, "lastHit": 1793880000000, "degree": 37 }],
  "edges": [{ "a": "米鱼", "b": "自己", "w": 12, "weight": 12 }],
  "total": 300,
  "omitted": 250
}
```

- `count`：这个实体在扫过的记忆里出现过几次。
- `lastHit`：**最近一次出现在哪条记忆里**（那条记忆的 `t`），0 = 扫过的范围里没有它。
  实体表只存次数、不存时间，这个值每次查询时按 `t` 倒着扫记忆现找，先撞上的就是最近的，找齐就停。
- `degree`：在**整张图**里连了几条边（不受 `limit` 影响）。
- 每条边 `a` ↔ `b` 的 `weight` 是共现次数；老字段 `w` 保留，值相同。

### `GET /dsh-whale-memory/graph/entity`

点一个实体，看它名下最近的几条记忆。

| 参数 | 缺省 | 说明 |
| --- | --- | --- |
| `name` | 必填 | 实体名；空 → 400 |
| `space` | `default` | 空间 |
| `limit` | `5` | 最多几条，上限 50 |

```json
{ "ok": true, "name": "米鱼", "space": "default", "count": 5,
  "items": [{ "id": 3021, "t": 1793880000000, "u": "……", "a": "……" }] }
```

查不到（这个名字下一条记忆都没有）→ **404** `{ "ok": false, "reason": "not-found" }`，不拿空数组冒充。
`u` / `a` 各截 300 字，和 `/entries` 一致。实体名本来就是从正文里切出来的线索词，所以用 `LIKE '%name%'` 就是精确的。

## 页面上长什么样

设置页「记忆内容 → 图谱」是一列**列表**，不是画布：

- 顶上一行：空间下拉（读 `/spaces`）、实体/边统计、`按出现次数排` ⇄ `按联系数排`。
- 每个实体一行：`▸ 名字` + `N 条 · 度 K · 最近出现在 MM-DD HH:MM`。
- 点名字展开它名下最近 5 条记忆；再点一条展开助手侧原文（数据来自 `/graph/entity`，不再另开一套详情）。
- 实体下面列它的前 5 条边：`A ↔ B ×权重`，点对端直接切过去。

空状态说实话：没有实体就说「这段记忆里还没攒出实体」；有实体没边就说「还没攒够共现，等记忆再多一点」，
并把阈值写出来——**一条边要被两条以上的记忆同时提到才留下（至少 2 次）**。

## 「最近召回」不是这里算的

场景页那行 `最近召回 HH:MM` 走的是另一条真实数据：`entries.lastHit`。
`warmEntries()`（`memory_recall` 真把条目交回给模型时）顺手写 `lastHit = 现在`；
场景取它名下 `entry_ids` 里最大的那个，一条都没被召回过就是 0 → 页面写「还没被召回」。

老库由 `lib/tidy.mjs` 的 `ensureHitColumns` 补列（`hits` / `tier` / `lastHit`），不迁移数据、不删行。

> 早先版本用 `meta` 里的 `sceneHit:*` 报「最近触发」。那枚键**从来没有写入方**（`markHit` 写了却没人调），
> 所以永远是空——0.28.18 起整块删掉，改读上面这条真数据。
