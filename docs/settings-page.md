# 设置页结构（分页签）

最后一版：`#tab=` 五条页签，一个区一页。这里只写「结构在哪、改哪儿」——文案口径
（每项说明 ≤25 字、后缀只写「默认 X」/「已改」、单位进名称括号）见 `README.md`。

## 一、页签 ↔ 区 ↔ 分组

| 页签（hash） | 区 id | 组（`zone`） | 常用 / 高级 |
| --- | --- | --- | --- |
| 它现在怎么想我（`#tab=mood`） | `now` | 情绪记账 | 2 / 3 |
| 记忆怎么收（`#tab=memory`） | `intake` | 注入与空间 · 联想 · 冷热分层 · 入库取舍 · 落盘与周记 · 压缩存档 · 日记 | 8 / 14 |
| 记忆内容（`#tab=content`） | `content` | 没有设置项：热区 / 冷区 / 场景 / 画像 / 图谱 / 空间（库里到底存了什么） | 0 / 0 |
| 怎么被叫醒（`#tab=wake`） | `wake` | 什么时候可以说话 · 免打扰 · 夜班 / 桌面页 | 2 / 7 |
| 危险与诊断（`#tab=diag`） | `diag` | 打分与调试（+ 三个按钮） | 1 / 6 |

- `ZONES`（`client.js` 顶部）= 页签表：`id`（now/intake/content/wake/diag，存 localStorage）、
  `slug`（mood/memory/content/wake/diag，进 hash）、`title`/`hint`/`long`。`content` 这一页
  没有 `GROUPS`（零设置项），`renderZone` 单独给它塞一块 `EntriesView`。
- `GROUPS[].zone` 决定某组分到哪一页；没有 `zone` 的按 `intake` 算。
- `tier: 'core' | 'adv'` 决定常用/高级；**页签不搬字段，只分页**（后端字段一个没少）。

## 二、切页的三条通路

1. **点页签**：`setTab(zone.id)`，纯 React 状态，不整页刷新。
2. **键盘**：`←/→`（浏览器全局 keydown，正在 `input/textarea/select/contenteditable` 里敲字时不抢键）。
3. **地址栏**：`#tab=<slug>`。开局按 `hash > localStorage > 第一页` 的顺序认；
   `hashchange` 时跟过去（点别人分享的链接会切页）。

写回：`localStorage` 键固定 `whale-memory.settings.tab`，存区 id；地址栏用
`history.replaceState` 写成 `#tab=<slug>`——不用 `location.hash`，因为后者会去找同名锚点、把页面滚走。
`parseTabHash` / `tabOf` 都是纯函数，`__test` 里直接测。

## 三、非当前页：全部渲染，只加 `hidden`

五页**都挂在 DOM 里**，非当前页 `hidden` + 行内 `display:none`（两条一起写：UA 的
`[hidden]{display:none}` 打不过行内 `display:flex`，只写属性会看着没生效）。

为什么这么选：

- 一行设置的草稿（`draft` / `typing`）是 `Row` 的组件状态，卸载就回到旧值——切页丢字比切页慢更不能接受；
- 切回来是瞬时的，也不用重建图谱/记忆内容那些子树；
- `hidden` 顺带把它移出无障碍树：屏幕阅读器只读当前页，`role="tabpanel"` + `aria-labelledby` 成对。

代价：首屏 DOM 里五页的节点都在（去标签后可见文本合计 596 字 / 静态 HTML 23 KB，其中一页可见）。

## 四、页内自成一块的计数

- 状态条四格（版本 / 条目 / 今日注入 / 情绪）**只在第一页顶部**，不每页重复。
- 诊断页自己的那条：`说话人覆盖 N / M 条 · P%`（`/status` 的 `speaker`），常显、不用点开高级；
  更细的七行（打分公式 / 门槛 / 三轴调试 / 取舍影子 / 向量服务 / 运行位置）仍在诊断页的「高级」里。
- 记忆内容自己占一条页签（`#tab=content`）：它是「现状」，不是设置，所以不跟第一页挤在一起。
  第一页只留状态条 + 只读预览（记忆卡 / 情绪 / 任务栈），不再挂任何列表。

## 五、记忆内容页：信息怎么排

一页六块，全部只读为主（写入口只有「改 / 撤回 / 切空间 / 删场景」，各自带一次确认）：

1. **每条记忆两行**。第一行是摘要（`nowrap` + 省略号，点了才展开全文、权重、情绪、助手那句、改/撤回）；
   第二行是 10px 的小字元信息。**收起状态只留四段**、一行排完：
   `空间 · 命中 N 次 · 最后想起 HH:MM（没命中过写「还没被想起」） · 热区/冷区`；
   三个「查账用」的字段**有值才占位**：`来源 <spk 前 8 位>`（`spk` 非空才出现）、
   `重要度 0.87`（`imp` 非 NULL 才出现，NULL 等于走自动公式）、`tier 2`（`tier > 0` 才出现）。
   点开之后第二行补全所有字段并允许折行：来源给全量、`重要度 自动`、`命中`、`tier`、
   `最后想起 MM-DD HH:MM`、`写入 MM-DD HH:MM`、`tier 变动 ≈ 最后想起 …`（库里没有单独的 tier 变动时间列，
   只有「最后一次被想起」说得准，所以写 ≈）。
   两行的渲染函数是 `entryRow(item, {open, onToggle, ...})`，元信息是 `entryMetaText(item, {open})`，
   页面与验收脚本共用这一份（`__test.entryRow` / `__test.entryMetaText`）。
2. **热区/冷区计数条**：两段纯 CSS 色块（`flex: N 1 0` 按条数分宽，`currentColor` + 两档 opacity），
   下面一行数字 `热 N（P%） · 冷 M（P%）`；两边都是 0 时整块不出现。数字来自 `/entries` 的 `counts`
   （同一空间/关键字口径下 hot 与 cold 各几条，一次请求拿全）。
3. **空间下拉 + 条目数徽标**：下拉只影响这一页看哪个空间（不改配置），右边徽标写 `空间 N 条`；
   真切换配置里的空间仍在「空间」那一栏（写 `space` 字段，带回执）。
4. **场景列表**：每条 `主题 · N 条记忆 · 最近召回 MM-DD HH:MM / 还没被召回 · 今天触发过 / 今天没触发`
   （`sameDay()` 按本地日历日比，`lastHit` 与今天同日就算「今天触发过」）。
5. **画像区**：先列卡片里「关于你的事实」实际取到的那几条原文（后端按 `listFacts + factMax` 同一口径给出），
   再逐行铺画像正文，`对方话里的情绪词` 那一行标「（旧名「情绪底色」，已改名）」。
6. **图谱**：图/列表两条视图不变，图上方多一行 `实体 N · 边 M · 本次画 K 条边`（K 来自 `buildGraphScene().stats.edgesDrawn`）。

**空状态**：每一块都是「一句还没有什么 + 一句为什么」，例如
`热区是空的。` / `热区为空：最近没有命中。热区按召回与权重重分层，命中过才会进来。`
（`emptyBox(what, why)`，`__test.emptyBox` 可直接渲染）。
